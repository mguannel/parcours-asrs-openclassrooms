# Parcours Administrateur systèmes, réseaux et sécurité — OpenClassrooms

Dépôt récapitulatif des projets réalisés et validés dans le cadre du parcours
**Administrateur d'infrastructures sécurisées** (OpenClassrooms, titre RNCP niveau 6).

Chaque projet fait l'objet d'un dossier dédié contenant les livrables, la
documentation technique et les schémas d'architecture associés.

> Le projet 1 (« Gérez les demandes au quotidien ») n'est pas repris ici : il s'agit
> d'un projet de découverte de la formation, sans livrable technique.

---

## Vue d'ensemble

| # | Projet | Domaine | Livrables |
|---|--------|---------|-----------|
| 02 | Concevoir le réseau local d'une startup | Réseau | Schéma logique, plan d'adressage, configuration |
| 03 | Concevoir une architecture n-tiers pour une PME | Architecture | Schéma n-tiers, dimensionnement, justification |
| 04 | Mettre en place des services web sécurisés | Web / Sécurité | Configuration serveur, TLS, durcissement |
| 05 | Raccorder une entité et ses postes au SI | Poste de travail | Procédure de raccordement, intégration AD |
| 06 | Déployer des services réseaux et équipements d'interconnexion | Réseau | VLAN, DNS/DHCP, routage, configuration |
| 07 | Superviser le SI | Supervision | Sondes, tableaux de bord, alerting |
| 08 | Gérer le parc informatique d'une PME | Parc / ITSM | Inventaire, procédures, gestion des actifs |
| 09 | Déployer une nouvelle solution de sauvegarde | Sauvegarde | Politique de sauvegarde, PRA, tests de restauration |
| 10 | Sécuriser le réseau d'une grande entreprise | Sécurité réseau | Pare-feu, segmentation, VPN, filtrage |
| 11 | Évaluer et améliorer la sécurité d'un domaine Windows et de l'AD | Sécurité AD | Audit AD, plan de remédiation, GPO |
| 12 | Migrer vers le cloud | Cloud | Étude de migration, architecture cible, plan de bascule |
